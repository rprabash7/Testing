# Manovastra - E-Commerce Platform

Premium Indian Ethnic Wear E-Commerce Website built with Django.

## Features

- 🛍️ Product Catalog with Categories
- 🎨 Multiple Color Variants
- ⭐ Rating & Reviews
- 💳 Razorpay Payment Integration
- 📧 Email OTP Verification
- 📦 Order Management
- 🔐 Manager Dashboard
- 📱 Responsive Design

## Tech Stack

- **Backend:** Django 6.0
- **Database:** SQLite3 (Development) / PostgreSQL (Production)
- **Payment:** Razorpay
- **Email:** Gmail SMTP
